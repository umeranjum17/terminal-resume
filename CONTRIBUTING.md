# Contributing to Umer Terminal

Thank you for your interest in contributing!

This project is an open-source terminal-style portfolio template. Most forks only need to edit `content/profile.ts` to make it their own.

## Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/terminal-resume.git
   ```
3. Install dependencies:
   ```bash
   pnpm install
   ```
4. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development

- Start the dev server: `pnpm dev`
- Lint before committing: `pnpm lint`
- Build to verify: `pnpm build`

## Customizing for Your Own Portfolio

Edit [`content/profile.ts`](/content/profile.ts) to update:

- Name, role, location, and contact info
- Experience, projects, skills, and education
- Terminal copy and commands

## Pull Request Guidelines

- Keep changes focused and minimal
- Describe what changed and why
- Ensure `pnpm build` and `pnpm lint` pass
- Update the README if you change how customization works

## Questions?

Open a [discussion](https://github.com/umeranjum17/terminal-resume/discussions) or issue.
